## 2. Intended detection (plain English)

A finding must be raised, at `Critical` severity, for every non-admin
principal that holds a `WriteKeyCredentialLink` control edge on a
target object whose effective ACL was not overridden by an explicit
deny. The attack vector is the "Shadow Credentials" technique: an
attacker who can write `msDS-KeyCredentialLink` on a victim account
attaches an attacker-controlled NGC/PKINIT public key to the account,
then performs PKINIT pre-authentication to mint a TGT for that account
and recover the NTLM hash via U2U / Kerberos extensions. The capability
is functionally equivalent to a password reset and applies to every AD
object class that ships with the `msDS-KeyCredentialLink` schema
attribute (`user`, `computer`, `msDS-GroupManagedServiceAccount`,
`msDS-ManagedServiceAccount`).

### 3.1 Effective SQL (copied from code)

```sql
SELECT e.source_sid, e.target_object_guid, o.distinguished_name, e.edge_id, e.control_type
FROM fact_control_edge e
INNER JOIN dim_object o ON e.target_object_guid = o.object_guid
WHERE e.control_type IN ($type0) AND e.deny_cancelled = 0
ORDER BY e.source_sid, e.target_object_guid, e.control_type
```

`$type0` is bound to the literal string `"WriteKeyCredentialLink"` (the
result of `ControlType.WriteKeyCredentialLink.ToString()`). The capture
pipeline writes `control_type` in the same form via
`ControlEdgeService.InsertEdge`, so the equality match is exact.

### 3.2 Post-SQL filters (in C#)

- `if (excludeAdmins && IsAdminSid(sid)) continue;` â€” `excludeAdmins`
  is `true` at the dispatch site. `IsAdminSid` matches RIDs in
  `AdminRids` = {500, 502, 512, 516, 518, 519, 520, 521, 526, 527} and
  every SID in `PrivilegedSystemSids`, but **explicitly returns
  `false`** for SIDs in `BroadSids` (`S-1-1-0` Everyone, `S-1-5-11`
  Authenticated Users, `S-1-5-7` Anonymous). Broad principals
  therefore **still fire** SEC-025 â€” same intentional posture as
  SEC-001 and SEC-024.
- `ContextJson` includes a `source_admin_classification` field via
  `ClassifyPrincipal`: `WellKnownAdmin` (unreachable here, filtered),
  `PrivilegedByMembership`, `BroadPrincipal`, `SystemOrExpectedBuiltIn`
  (unreachable, filtered), or `NonPrivileged`.

## 12. Defects / deferred items

1. `[IMP-CTRL-SCOPE]` â€” **RESOLVED.** SEC-025 now matches the
   property-write equivalence set
   `RuleEvaluatorHelpers.PropertyWriteEquivalents(WriteKeyCredentialLink)`
   = `{WriteKeyCredentialLink, GenericAll, GenericWrite,

   (`WriteDacl` / `WriteOwner` / `Owns`) intentionally excluded â€” they are
   SEC-004 / SEC-005's domain (admin targets) and SEC-060's (broad
   sources). Pin `WhenNoKeyCredentialLinkEdgeExists_ThenSEC025DoesNotFire`

   The widened set is gated on `o.object_class IN ('user', 'computer',

   `WhenGenericAllOnGroupTarget_ThenSEC025DoesNotFire`. (sMSA omitted â€” no

3. `[IMP-DEL-OBJ]` â€” The SQL joins `dim_object` without filtering

6. `[IMP-CAT-WORDING]` â€” The catalog description "*A principal can

   "*A non-admin principal can write the `msDS-KeyCredentialLink`

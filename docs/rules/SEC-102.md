## 1. Catalog claim (verbatim from `rules.yaml`)

```yaml
- id: SEC-102
  name: "Risky gMSA Password Retrieval Principal"
  description: >-
    A broad, unresolved, or non-privileged principal can retrieve the managed password for a Group Managed Service Account. This can expose service credentials for lateral movement or privileged access if the gMSA is high value.
  severity: High
  category: CredentialTheft
  remediation: >-
    Restrict PrincipalsAllowedToRetrieveManagedPassword to the specific computers or tightly controlled groups that host the service. Remove broad principals and investigate unresolved SIDs.
  mitre: T1552
  tags: ["service-account", "gmsa", "credential-theft", "managed-password"]
```

Source: `src/SecureAD.Core/Findings/Rules/rules.yaml` line 478.

## 2. Intended detection (plain English)

For every captured gMSA, look at who is allowed to retrieve its managed password (`PrincipalsAllowedToRetrieveManagedPassword`, persisted as `dim_delegation.delegation_type = 'GmsaPasswordReader'`). Raise a finding when the allowed reader is **(a)** a broad principal (Everyone / Authenticated Users / Anonymous / BUILTIN\Users / Domain Users), **(b)** an unresolved SID (no `dim_object`, `dim_principal.resolution_state = 'Unresolved'`), or **(c)** a non-privileged principal when the gMSA itself is a privileged principal.

### 3.1 Effective SQL

```sql
SELECT gmsa.object_guid,
       gmsa.distinguished_name,
       gmsa.sid,
       d.target AS reader_sid,
       COALESCE(p.display_name,
                CASE WHEN reader_object.distinguished_name IS NOT NULL
                     THEN SUBSTR(reader_object.distinguished_name, 4, INSTR(reader_object.distinguished_name, ',') - 4)
                     ELSE NULL END) AS reader_name,
       p.resolution_state,
       reader_object.sid AS reader_object_sid
FROM dim_delegation d
INNER JOIN dim_object gmsa ON d.object_guid = gmsa.object_guid
LEFT JOIN dim_principal p ON d.target = p.sid
LEFT JOIN dim_object reader_object ON d.target = reader_object.sid
WHERE d.delegation_type = 'GmsaPasswordReader'
  AND gmsa.is_deleted = 0
  AND gmsa.object_class = 'msDS-GroupManagedServiceAccount'
ORDER BY gmsa.distinguished_name, d.target
```

### 3.2 Post-SQL filters (in C#)

Reasons are accumulated (not first-match-wins). A finding is emitted only if at least one reason matches:

```text
reasons = []
if SourceIsBroadPrincipal                                          add "broad principal"
if reader_object_sid IS NULL AND resolution_state = 'Unresolved'    add "unresolved SID"
if gmsa_sid is privileged AND classification = NonPrivileged        add "non-privileged principal can retrieve privileged gMSA password"
if reasons is empty                                                no finding
```

`Detail` joins matching reasons with `"; "`. `ContextJson["reasons"]` holds the full list; `ContextJson["reason"]` retains the first match for backward compatibility.

`SourceIsBroadPrincipal` is `BroadSids ∪ {S-1-5-32-545}` ∪ any SID ending in `-513` (Domain Users). See `RuleEvaluatorHelpers.IsBroadPrincipalSid` (line 119).

## 5. Exclusions (and the reason each is correct)

| Exclusion | Mechanism | Justification |
| --- | --- | --- |
| Deleted gMSAs | `gmsa.is_deleted = 0` | Tombstones cannot be exercised; would otherwise produce false positives. Added this session. |
| Non-gMSA delegation rows | `gmsa.object_class = 'msDS-GroupManagedServiceAccount'` | Rule is gMSA-specific by design. |
| Non-`GmsaPasswordReader` rows | `delegation_type = 'GmsaPasswordReader'` | Only this attribute grants password retrieval. |
| Privileged readers (Domain Admins, SYSTEM, etc.) on a non-privileged gMSA | falls through reason chain → no reason → skipped | A DA reading a gMSA is expected. |
| Privileged-by-membership reader on a privileged gMSA | reason (c) requires `classification == NonPrivileged` | Treated as expected delegation. |
| Resolved non-broad non-privileged reader on a non-privileged gMSA | no reason matches | Outside catalog claim. |

## 8. Edge cases considered

| # | Scenario | Resolution |
| --- | --- | --- |
| E1 | Multiple allowed readers on the same gMSA | SQL returns one row per `(gmsa, reader_sid)`; one finding per qualifying reader. `FindingKey` uses subject SID + target GUID. |
| E2 | gMSA has no `PrincipalsAllowedToRetrieveManagedPassword` set | No `dim_delegation` row → no finding. Intentional. |
| E3 | Reader is a group, not a principal | The SQL treats `d.target` as a SID; group SIDs work too. The "broad" check correctly catches `S-1-5-11`, BUILTIN\Users, and `-513`. Other groups must rely on reason (c). |
| E4 | gMSA marked privileged-by-membership but `dim_principal` missing | `IsPrivilegedPrincipal` returns true via the precomputed set. Acceptable. |
| E5 | Unresolved reader where the SID happens to start `S-1-5-21-…-512` (admin RID) | `IsAdminSid` true → `classification == WellKnownAdmin` → reason (c) excluded; reason (b) requires `Unresolved` resolution state. Edge could double-count; verify with a test. |
| E6 | `dim_principal` row exists but `resolution_state` is `null` | reason (b) requires literal string `Unresolved`; null is skipped. Consistent with catalog claim. |
| E7 | Reader is a broad principal AND gMSA is privileged | First matching reason wins; reason (a) reported. Detail loses the "privileged gMSA" context. Documented in §12. |
| E8 | Coverage incomplete for `Objects` or `Principals` | No coverage requirement entry exists today (the bug that surfaced this card). Stamping behaviour is the default. |

## 9. Output assertions (`Detail` and `ContextJson`)

The finding produced must include:

- `RuleId == "SEC-102"`
- `Severity == Severity.High`
- `SubjectSid` = `reader_sid` (the allowed reader)
- `TargetKind == "object_guid"`
- `TargetId` = gMSA object GUID (`D` format)
- `FindingKey == "SEC-102|{reader_sid}|{gmsa_guid}"`
- `Detail` contains the chosen `reason` literal(s), joined with `"; "`: one or more of `"broad principal"`, `"unresolved SID"`, `"non-privileged principal can retrieve privileged gMSA password"`.
- `ContextJson` is non-null and contains keys:
  - `"evidence_type": "gmsa_password_retrieval"`
  - `"condition": "RiskyGmsaPasswordReader"`
  - `"object_dn"` = gMSA DN
  - `"object_sid"` = gMSA SID
  - `"reader_sid"` = allowed reader SID
  - `"reader_name"` = resolved display name or DN-derived CN
  - `"reader_classification"` ∈ {`BroadPrincipal`, `NonPrivileged`, `PrivilegedByMembership`, `WellKnownAdmin`, `SystemOrExpectedBuiltIn`, `Unknown`}
  - `"target_is_privileged"` boolean
  - `"reason"` = first matched reason (backward compatibility)
  - `"reasons"` = JSON array of every matched reason in evaluation order
  - `"object_guid"` = gMSA GUID

## 1. Catalog claim (verbatim from `rules.yaml`)

```yaml
- id: SEC-083
  name: "Group Policy Preferences Password Exposure"
  description: >-
    A Group Policy Preferences XML file in SYSVOL contains a cpassword attribute (MS14-025 / CVE-2014-1812). The password is AES-encrypted with a key Microsoft published, so any authenticated user who can read SYSVOL can decrypt it.
  severity: Critical
  category: CredentialTheft
  remediation: >-
    Remove the affected Group Policy Preferences items that store credentials and rotate the exposed account passwords. Apply MS14-025 to prevent new cpassword items from being created.
  mitre: T1552.006
  tags: ["gpp", "cpassword", "credential-theft", "sysvol", "ms14-025"]
```

## 2. Intended detection (plain English)

Fire once per Group Policy Preferences `cpassword` occurrence captured from SYSVOL. The AES key for `cpassword` is public (MS14-025), so any authenticated user who can read SYSVOL can recover the credential. Detection is **presence-only**: the capture records the file/element/account, never the password or the ciphertext.

### 3.1 Effective SQL

```sql
SELECT s.gpo_guid, s.setting_key, s.setting_value, gpo.distinguished_name
FROM dim_gpo_setting s
INNER JOIN dim_object gpo ON s.gpo_guid = gpo.object_guid
WHERE s.source_file = 'GPP' AND s.section = 'cpassword'
ORDER BY s.gpo_guid, s.setting_key
```

`setting_key` shape is `"<file>|<element>|<account>"` (parsed by `SplitGppKey`); `setting_value` carries the account (or element type) — **never** a password.

### 3.2 Post-SQL filters (C#)

None beyond the SQL. One finding per row, keyed by `setting_key` (`findingKeyDiscriminator`), so N cpassword items in one GPO produce N findings. Subject SID is empty (the finding is object-centric, keyed to the GPO).

## 5. Exclusions (and the reason each is correct)

| Exclusion | Mechanism | Justification |
| --- | --- | --- |
| Non-GPP / non-cpassword settings | SQL `source_file = 'GPP' AND section = 'cpassword'` | Only GPP cpassword items carry the MS14-025 exposure. |
| GPO not in `dim_object` | `INNER JOIN dim_object` | Without the directory object the exposure cannot be attributed to a GPO. |

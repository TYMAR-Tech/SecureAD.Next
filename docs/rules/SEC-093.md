## 1. Catalog claim (verbatim from `rules.yaml`)

```yaml
- id: SEC-093
  name: "LAPS Decryptor is a Broad Principal"
  description: >-
    The Windows LAPS authorized decryptor (the ADPasswordEncryptionPrincipal value configured in SYSVOL Registry.pol), or one of its effective members, is a broad principal such as Everyone, Authenticated Users, or Domain Users. Windows LAPS encrypts the managed password against this single principal, so a broad decryptor lets any member decrypt every affected computer's local administrator password.
  severity: Critical
  category: CredentialTheft
  remediation: >-
    Set the Windows LAPS ADPasswordEncryptionPrincipal policy to a tightly scoped administrative group and remove broad principals from its effective membership. Rotate affected LAPS passwords after correcting the decryptor.
  mitre: T1003.003
  tags: ["laps", "credential-theft", "decryptor", "sysvol"]
```

## 2. Intended detection (plain English)

Windows LAPS (CNG DPAPI) encrypts each managed password against **exactly one** principal — the `ADPasswordEncryptionPrincipal` configured via Group Policy (stored in SYSVOL `Registry.pol`). Fire when that decryptor **is**, or **effectively includes** (via nested membership), a broad principal (Everyone / Authenticated Users / Domain Users / etc.), because any member can then decrypt every affected computer's local-admin password regardless of directory ACLs. A merely *non-admin* scoped decryptor group is **not** flagged — least-privilege delegation to a scoped wrapper group is the documented, supported pattern.

### 3.1 Effective SQL (decryptor load)

```sql
SELECT s.gpo_guid, s.setting_value, gpo.distinguished_name, gpo.domain_fqdn
FROM dim_gpo_setting s
INNER JOIN dim_object gpo ON s.gpo_guid = gpo.object_guid
WHERE s.source_file = 'Registry.pol'
  AND s.section LIKE '%Policies\LAPS'
  AND s.setting_key = 'ADPasswordEncryptionPrincipal'
  AND s.setting_value IS NOT NULL AND TRIM(s.setting_value) != ''
ORDER BY s.gpo_guid
```

### 3.2 Resolution + decision (C#)

For each configured decryptor:
1. `ResolveDecryptor` maps the value to a principal SID and its effective membership.
2. **Unresolved** → emit a finding with `CoverageComplete = false` + a coverage reason (surface, don't drop).
3. **Resolved and not broad** → skip (intentional scoped delegation).
4. **Resolved and broad (self or nested)** → emit the Critical finding, listing the broad principal names.

If `dim_gpo_setting` is absent (DB captured without SYSVOL) the rule is silently inapplicable.

## 5. Exclusions (and the reason each is correct)

| Exclusion | Mechanism | Justification |
| --- | --- | --- |
| Scoped non-admin decryptor group | `resolution.BroadSids.Count == 0` → skip | Least-privilege delegation to a scoped group is the supported pattern, not a finding. |
| No decryptor configured / blank value | SQL `setting_value` non-null/non-blank | Nothing to evaluate. |
| `dim_gpo_setting` absent | `TableExists` short-circuit | No SYSVOL capture ⇒ rule inapplicable (not a false negative). |
| GPO not in `dim_object` | `INNER JOIN dim_object` | Cannot attribute the config to a GPO. |
